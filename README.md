# My Notes App

A simple Android application for creating and displaying notes. The app uses `RecyclerView` to display a list of notes saved in `SharedPreferences`. Users can add new notes, view their content, and save them for later.

## Features

- Add notes with a title and content.
- View saved notes in a list.
- Tap on a note to see its details.
- Simple and user-friendly interface.

## Technologies Used

- **Android SDK**: For building the Android app.
- **RecyclerView**: For displaying the list of notes.
- **SharedPreferences**: For storing notes locally.
- **Java**: Programming language for app development.
